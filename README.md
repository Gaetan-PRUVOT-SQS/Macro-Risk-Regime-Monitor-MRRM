# Macro-Risk-Regime-Monitor-MRRM
Macro Risk Regime Monitor (MRRM) est un dashboard open-source mesurant le stress macro-financier via PCA dynamique et détectant les régimes de marché (Risk-On, Neutral, Stress). EN Macro Risk Regime Monitor (MRRM) is an open-source dashboard measuring macro-financial stress using dynamic PCA and detecting market regimes (Risk-On, Neutral, Stress).
